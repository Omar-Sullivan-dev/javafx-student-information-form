# JavaFX Student Information Form

A JavaFX desktop-interface project that demonstrates form design, layout management, control styling, event handling, and exit confirmation.

## Project Overview

This project creates a Student Information form with fields for entering and viewing student details. It was developed as part of Java Programming II coursework using JavaFX and NetBeans.

## Interface Fields

* Student ID
* First Name
* Last Name
* Email
* GPA

## Interface Controls

* Find
* Insert
* Delete
* Update
* Exit

The Exit button and the window’s close button display a confirmation dialog before closing the application.

## Technical Features

* JavaFX application lifecycle
* `BorderPane` main layout
* `GridPane` form layout
* `HBox` button layout
* Labels and text fields
* Button event handling
* Confirmation alerts
* Window-close event handling
* Fonts, colors, padding, spacing, borders, and rounded corners
* Reusable exit-confirmation method

## Layout Structure

| Section | JavaFX Component | Purpose                                  |
| ------- | ---------------- | ---------------------------------------- |
| Top     | `Label`          | Displays the Student Information heading |
| Center  | `GridPane`       | Organizes labels and text fields         |
| Bottom  | `HBox`           | Arranges the action buttons              |
| Root    | `BorderPane`     | Combines the interface sections          |
